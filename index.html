Terminal de utilidades

Una caja de herramientas del lado del cliente: nada se envía a ningún servidor salvo donde se indique explícitamente (IP pública, QR). Todo el procesamiento corre en tu navegador.

$ ls herramientas/ → passgen, strength, hash, base64, urlcodec, textconv, jwtdecode, uuidgen, qrgen, whoami
01passgen — generador de contraseñas

Genera contraseñas aleatorias usando crypto.getRandomValues (criptográficamente seguro, no Math.random).

02strength — comprobador de fuerza

Estima entropía y tiempo aproximado de fuerza bruta. Se calcula localmente; nada se transmite.

—
  • Al menos 12 caracteres
  • Contiene mayúsculas
  • Contiene minúsculas
  • Contiene números
  • Contiene símbolos
03hash — generador de hashes

Calcula SHA-1 / SHA-256 / SHA-384 / SHA-512 con la Web Crypto API nativa del navegador.

04base64 — codificar / decodificar

Codifica o decodifica texto en Base64 (soporta UTF-8).

05urlcodec — codificar / decodificar URL

Aplica encodeURIComponent / decodeURIComponent.

06textconv — texto ⇄ binario ⇄ hex

Convierte texto plano a binario o hexadecimal, y viceversa.

07jwtdecode — inspector de JWT

Decodifica header y payload de un JWT (Base64URL). No verifica la firma ni valida su autenticidad.

08uuidgen — generador de UUID v4

Genera identificadores únicos universales versión 4 usando crypto.randomUUID.

09qrgen — generador de código QR

Genera un código QR a partir de texto o URL (renderizado localmente en el navegador).

10whoami — info de red y navegador

Consulta tu IP pública (vía api.ipify.org) e info básica de tu navegador. Esta es la única herramienta que hace una petición externa.
